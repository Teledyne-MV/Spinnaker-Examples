# AcquisitionGenDC

## Overview 

 AcquisitionGenDC demonstrates how to acquire multi-component images using the GenDC (Generic Data Container) payload format. This example is specifically for cameras that support GenDC. GenDC is a standardized container format that allows cameras to transmit multiple data components (images, metadata, etc.) in a single synchronized payload. This is useful for multi-sensor cameras, stereo cameras, or cameras with multiple data streams such as intensity + depth.
